# Тесты: fake-модель

`model/fake` — модель по сценарию. Каждый вызов получает следующий шаг, все запросы записываются. Ход агента
становится детерминированным, и его можно проверять как обычную функцию.

```go
m := fake.New(
    fake.ToolCall("search", searchIn{Query: "vpn"}).WithText("Сейчас поищу."),
    fake.Text("Нашёл: VPN выдаёт отдел инфраструктуры.").Expect(func(req model.Request) error {
        last := req.Messages[len(req.Messages)-1]
        if last.Role != model.RoleTool {
            return fmt.Errorf("model did not get the tool result: %+v", last)
        }
        return nil
    }),
)
res, err := agent.New(m, agent.Tools(set)).Run(ctx, turn)
```

| Шаг | Что вернёт модель |
|---|---|
| `fake.Text(s)` | текст |
| `fake.ToolCall(name, args)` | один вызов инструмента. `args` сериализуется в JSON, ID вызова — `call_<name>` |
| `.WithText(s)` | текст перед вызовом, как модель, «думающая вслух» |
| `fake.JSON(v)` | `v` в JSON, как ответ под `Format` |
| `fake.Fail(err)` | ошибка, например `model.ErrUnavailable` |
| `.Expect(func(model.Request) error)` | проверка запроса этого шага. Ошибка проверки становится ошибкой вызова |

После хода:
- `m.Calls()` — все запросы к модели: какие инструменты предложены, что в истории;
- `m.Remaining()` — сколько шагов осталось. Ноль значит, что сценарий отыгран целиком.

Сценарий кончился — `fake.ErrScriptExhausted`. `Stream` отдаёт текст по словам, так что стриминг тоже
проверяется. `fake.NewEcho(text)` отвечает одним текстом на всё: годится для демо и работы над UI без модели.

## Что проверять

- **Золотые диалоги:** вопрос → ожидаемые вызовы инструментов с аргументами → итоговый текст и события.
- **Права:** под каждым вызывающим `m.Calls()[0].Tools` содержит только разрешённое, а вызов скрытого по имени
  даёт `forbidden` в сообщении инструмента.
- **Отказы:** `fake.Fail(model.ErrUnavailable)` на любом шаге. Ход падает с ошибкой, трасса заполнена до сбоя.
- **Проверки ответа:** шаг без инструментов → в следующем запросе твоя заметка последней системной репликой.

На живой модели те же сценарии гоняй отдельно и много раз: ответы модели плавают, и одного прогона мало.

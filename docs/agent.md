# agent: цикл хода

```go
a := agent.New(m,
    agent.Tools(set),
    agent.Policy(policy),
    agent.MaxToolSteps(6),
    agent.Timeout(80*time.Second),
    agent.WrapModel(logModel),
    agent.WrapTool(audit, confirm),
    agent.Checks(grounded, redact),
)
res, err := a.Run(ctx, turn)
```

`Agent` неизменяемый и безопасен для параллельных ходов. Один агент на приложение — нормально.

## Опции

| Опция | По умолчанию | Что делает |
|---|---|---|
| `Tools(set)` | пусто | инструменты. Без них агент — обычный чат |
| `Policy(p)` | `nil`, всё разрешено | кто какие инструменты видит и вызывает |
| `MaxToolSteps(n)` | 6 | сколько вызовов модели могут просить инструменты. Следующий идёт без инструментов и с заметкой, что они кончились |
| `LastStepNote(s)` | английская фраза «answer now» | текст этой заметки |
| `Timeout(d)` | 80 с | лимит хода с момента получения модели |
| `MaxRetries(n)` | 1 | сколько раз проверки могут вернуть модель за новым ответом |
| `TraceLimit(n)` | 4000 | обрезка результатов инструментов в трассе, в байтах. 0 — не резать |
| `WrapModel(mw...)` | — | middleware вокруг каждого вызова модели |
| `WrapTool(mw...)` | — | middleware вокруг каждого вызова инструмента |
| `Checks(c...)` | — | проверки финального ответа, по порядку |

## Turn

| Поле | Что это |
|---|---|
| `System` | системный промпт. Пустой не отправляется |
| `Messages` | история и новое сообщение, от старых к новым. Агент её не режет: сколько истории слать, решает приложение |
| `ReasoningEffort` | перекрывает настройку модели на этот ход |
| `Caller` | кто спрашивает. Попадает в контекст для политики и обработчиков |
| `Stream` | колбэки хода, все необязательные |

### Stream

| Колбэк | Когда |
|---|---|
| `Waiting()` | модель занята, ход ждёт место в пуле |
| `Delta(text)` | очередной кусок ответа |
| `Reset()` | забудь показанный текст: модель пошла вызывать инструменты или проверка попросила новый ответ |
| `ToolCall(call)` | сейчас выполнится инструмент. Удобно для статуса «ищу…» |
| `Event(e)` | инструмент отправил событие |

Колбэки вызываются в горутине хода, синхронно. Долгую работу (запись в сеть) уноси из них в канал.

## Result

| Поле | Что это |
|---|---|
| `Text` | финальный ответ после проверок |
| `Messages` | ход так, как его видела модель после `Turn.Messages`: вызовы инструментов, результаты, ответ. Добавь в историю целиком, если модели нужны прошлые результаты, или только ответ, чтобы экономить контекст |
| `Events` | события инструментов по порядку |
| `Usage` | токены за весь ход |
| `Trace` | трасса, заполнена даже при ошибке |

## Ошибки Run

- `ErrNoMessages` — пустой `Turn.Messages`.
- Ошибка `Acquire`, если модель — `Provider`.
- Ошибка модели или middleware модели, обёрнутая в `model: …`.
- Отмена или таймаут `ctx`: `context.DeadlineExceeded`, `context.Canceled`.

Ошибки инструментов ход не роняют. Модель получает код ошибки и решает, что делать дальше.

## Middleware

```go
type ModelMiddleware func(next ModelFunc) ModelFunc
type ToolMiddleware  func(next ToolFunc) ToolFunc
```

Первая переданная обёртка — внешняя. Middleware вокруг модели видит каждый запрос и ответ: логирует, считает
токены, добавляет заметку в запрос, повторяет вызов. Middleware вокруг инструмента видит каждый вызов:

```go
// Подтверждение человеком для опасных инструментов.
confirm := func(next agent.ToolFunc) agent.ToolFunc {
    return func(ctx context.Context, c model.ToolCall) (json.RawMessage, error) {
        if c.Name == "delete_file" && !askUser(ctx, c) {
            return nil, tool.ErrForbidden // модель получит "forbidden" и пойдёт дальше
        }
        return next(ctx, c)
    }
}
```

## Проверки ответа

```go
type Check func(ctx context.Context, a *agent.Answer) (retry string)
```

Проверка получает финальный текст и то, что было в ходе: `ToolCalls`, `Events`, `Steps`. Она может:
- **переписать** `a.Text`: убрать выдуманные ссылки, замаскировать секреты. Следующая проверка видит новый текст;
- **вернуть модель за новым ответом**: непустая строка уходит модели системной заметкой, на экране срабатывает
  `Stream.Reset`. Заметки всех проверок склеиваются. Когда `MaxRetries` исчерпан, ответ остаётся как есть, а в
  `Trace.Notes` появляется пометка.

```go
grounded := func(_ context.Context, a *agent.Answer) string {
    if a.ToolCalls == 0 && len(a.Text) > 300 {
        return "You explained this from memory. Search first, then answer."
    }
    return ""
}
```

## Трасса

`Trace` состоит из шагов (`Steps`) и заметок агента (`Notes`) и сериализуется в JSON. Каждый шаг — один вызов
модели:
- длительность и токены;
- текст, который модель написала, в том числе перед вызовом инструментов;
- вызванные инструменты: аргументы, код (`ok` или код ошибки), результат и длительность.

Сохраняй трассу каждого хода, хотя бы в лог. Без неё отладка агента превращается в гадание.

## Чего агент не делает

Не хранит историю, не режет контекст, не собирает промпт из частей, не ретраит сбои модели (это `MaxRetries` у
адаптера или пул), не ставит ходы в очередь. Это слой приложения поверх агента.
